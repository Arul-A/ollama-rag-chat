# LocalAI-RAG Client (Frontend)

This is the React + Vite frontend for **LocalAI-RAG**, styled with Tailwind CSS.

For complete project setup, prerequisites, and backend instructions, please refer to the main [Root Documentation](../README.md).

## Quickstart

```bash
npm install
npm run dev
```

Runs the application on `http://localhost:5173`. Make sure the FastAPI backend is running on `http://localhost:8000`.
